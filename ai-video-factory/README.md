An open-source, programmatic automated production pipeline built to generate viral short-form user-generated content (UGC) video ads from a single product text keyword input. 
This infrastructure completely bypasses expensive proprietary media SaaS applications (like HeyGen, ElevenLabs, or Runway) by orchestrating localized models and native Python automation scripts.
## 🛠️ Architecture Workflow
1. **Scripting Engine:** Uses a localized **LLaMA 3** framework via **Ollama** to analyze product inputs and programmatically generate high-converting ad scripts featuring hooks and emotional CTAs.
2. **Audio Generation Engine:** Utilizes Python asynchronous processes and **Edge-TTS** vectors to handle hyper-expressive vocal pacing.
3. **Video Assembly Layer:** Runs programmatically optimized video tracks via **MoviePy** and **FFmpeg** to merge audio channels and layout parameters smoothly.
## 📂 Project Structure
- `app.py`: Standard orchestration layer for prompt pipeline operations and data streams.
- `voice.mp3`: Output voice element payload generated by the local TTS framework.
- `output_ad.mp4`: Final 9:16 vertical platform-native video asset.
## ⚙️ Quickstart Installation
Ensure you have Python 3.10+ installed on your computer.
1. Clone the repository framework:
```bash
git clone https://github.com
cd ai-ugc-video-factory
```
2. Set up dependencies:
```bash
pip install moviepy fastapi uvicorn requests python-dotenv edge-tts asyncio
```
3. Initialize local models:
Ensure your background Ollama engine is live and the core model is pulled:
```bash
ollama run llama3
```
4. Run production pipeline:
```bash
python app.py
```
